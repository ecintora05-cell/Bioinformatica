Introducción

El paquete Biostrings en R es una herramienta robusta y ampliamente utilizada en el campo de la bioinformática para la manipulación y análisis de secuencias biológicas, como ADN, ARN y proteínas (secuencias de aminoácidos). Este paquete forma parte del proyecto Bioconductor, un repositorio especializado en el análisis de datos genómicos y biológicos en R. Biostrings está diseñado para manejar secuencias de manera eficiente y escalable, lo que lo convierte en una herramienta fundamental para el análisis de grandes volúmenes de datos biológicos generados por tecnologías de secuenciación de alto rendimiento.

El paquete se estructura en torno a la clase central XString, que representa secuencias biológicas y sus diferentes variantes (DNAString, RNAString y AAString), lo que permite una manipulación flexible y precisa de las secuencias de nucleótidos y aminoácidos. Las secuencias pueden ser manipuladas como objetos nativos en R, permitiendo realizar operaciones complejas con facilidad, como la búsqueda de patrones específicos dentro de las secuencias, coincidencia de patrones con tolerancia a errores (por ejemplo, mutaciones o alineaciones parciales), y alineación de secuencias, tanto global como local, lo que facilita estudios comparativos entre genes, proteínas, o regiones genómicas.

Además, Biostrings incluye herramientas para trabajar con múltiples secuencias a través de clases como XStringSet y XStringViews, que permiten la manipulación eficiente de conjuntos de secuencias y la creación de vistas de regiones específicas dentro de ellas. Estas funcionalidades son clave en análisis de datos a gran escala, como en estudios genómicos, transcriptómicos y proteómicos, donde el manejo eficiente de secuencias largas y múltiples alineaciones es crucial para la obtención de resultados significativos.

Otra característica importante de Biostrings es su integración con otros paquetes de Bioconductor, como GenomicRanges y IRanges, lo que permite trabajar de manera fluida con coordenadas genómicas y realizar análisis complejos que combinan la información de las secuencias con datos genómicos anotados. Esta sinergia facilita la construcción de pipelines bioinformáticos personalizados para abordar preguntas de investigación en biología molecular, evolución, y biomedicina.

Biostrings ofrece un conjunto de herramientas potente y flexible para los investigadores en biología computacional, proporcionando métodos eficientes y escalables para el análisis de secuencias biológicas, lo que lo convierte en un paquete esencial dentro del ecosistema de Bioconductor para análisis de datos genómicos y proteómicos.

Las clases de cadenas que estan disponibles en Biostrings son:

  1. DNAString[Set]: Secuencias de DNA.
  2. RNAString[Set]: Secuencias de RNA.
  3. AAString[Set]: Secuencias de Amino Acids (proteínas).
  4. BString[Set]: Big sequences, cualquier letra.

Se pueden leer secuencias, sin que marque error, de nucleótidos como AAStringSet o con BString sin embargo no va a hacer bien las operaciones que les pidan, tengan cuidado con eso.

Funciones basicas

  • length, names.
  • c and rev (reverso de la secuencia).
  • width, nchar (numero de carateres en una secuencia).
  • ==, duplicated, unique.
  • as.charcater or toString: convierte a un vector de caracteres.
  • sort, order.
  • chartr: convert letras en otras.
  • subseq, subseq<-, extractAt, replaceAt.
  • replaceLetterAt.

Clase XStringViews

La clase XStringViews se utiliza para representar un conjunto de “vistas” sobre un objeto XString, típicamente para almacenar patrones encontrados en una secuencia.

# Crear vistas sobre un DNAString
views <- Views(dna, start=c(1, 5, 8), end=c(3, 7, 10))

Subconjuntos de Vistas: Usa [ ] para subconjuntos y [[ ]] para extraer vistas individuales.

##Manipulación de secuencias con Biostrings

Una vez que tengas las secuencias (por ejemplo, ADN, ARN o proteínas), Biostrings proporciona una variedad de funciones para manipularlas.

Funciones clave

1. Complemento inverso:

reverseComplement(dna)
12-letter DNAString object
seq: AGTCAGCTACGT

2. Traducción (ADN a proteína):

translate(dna)
4-letter AAString object
seq: T*LT

3. Subsecuencias:

subseq(dna, start=4, end=10)
7-letter DNAString object
seq: TAGCTGA

4. Frecuencias de nucleótidos:

  • alphabetFrequency: Tabular todas las letras en la secuencia.
  • letterFrequency: Tabular letras específicas.

Operaciones de Entrada/Salida

Biostrings admite la lectura y escritura de datos de secuencias en varios formatos como FASTA, FASTQ y PHYLIP.

Lectura de archivos FASTA:

fasta_sequences <- readDNAStringSet("~/Downloads/GCF_000005845.2_ASM584v2_genomic.fna")

Escritura en FASTA:

writeXStringSet(fasta_sequences, "output.fasta")

Ejercicios

Ejercicio 1: Creación y manipulación de secuencias

  • Crea un objeto DNAString con la secuencia “AGTCGTAGC”.
  • Encuentra el complemento inverso de la secuencia.
  • Cuenta las ocurrencias del nucleótido “A”.
  • Extrae la subsecuencia de la posición 3 a la 7.

Ejercicio 2: Coincidencia de patrones

  • Crea un objeto DNAString con la secuencia “AGTCAGCTAG”.
  • Encuentra todas las coincidencias exactas del patrón “AGC”.
  • Realiza coincidencias aproximadas del patrón “AGC” permitiendo 1 desajuste.

Ejercicio 3: Alineación de secuencias

  • Realiza una alineación global entre las secuencias “ACGT” y “AGCT”.
  • Realiza una alineación local entre las secuencias “ACGT” y “CG”.
  • Escribe el resultado de la alineación en un archivo.
